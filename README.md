# Reflecta

Reflecta is a cross-platform mobile application built using React Native and Expo.  
The app focuses on a clean, minimal user experience with smooth navigation and scalable component design.

## Features
- Cross-platform mobile support (Android & iOS)
- Multi-screen navigation
- Clean and minimal UI
- Component-based architecture
- Responsive layouts for different screen sizes

## Tech Stack
- React Native
- Expo
- JavaScript

## Getting Started
1. Clone the repository  
2. Install dependencies using `npm install`  
3. Start the app using `npx expo start`

## Notes
This project focuses on mobile UI/UX, navigation flow, and scalable component structure.
